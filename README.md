# EBAC Sports

Projeto de loja de artigos esportivos desenvolvido no exercício da EBAC. O estado
do carrinho e dos favoritos é gerenciado com Redux Toolkit, e os produtos são
carregados da API com RTK Query.

## Tecnologias

- React e TypeScript
- Redux Toolkit e React Redux
- RTK Query para buscar e armazenar em cache os produtos
- styled-components

## Como executar

```bash
npm install
npm start
```

O app será aberto em [http://localhost:3000](http://localhost:3000).
